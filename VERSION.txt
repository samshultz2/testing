SOLVER CONSTRAINTS:
==================
1.  Maths not P1 (SSS1/SSS2/SSS3) - hardcoded in CLASS_SPECIFIC_RESTRICTIONS
2.  Chemistry not P1 (SSS1/SSS2) - from GenSubjectConfig.not_first_period
3.  No subject spanning break - prevents same subject before AND after break
4.  Teacher max 2 consecutive - rest required after every 2 periods
5.  Teacher unavailability - from GenTeacherAvailability table
6.  Teacher clashes - no double-booking same slot
7.  Teacher daily limits - from GenTeacher.max_periods_per_day
8.  No back-to-back diff subjects - same teacher/class can't have different subjects consecutively
9.  Double periods - from database (GenClassStreamSubject, GenSubjectConfig)
10. Subject clash avoidance - DATABASE DRIVEN (GenSubjectClashRule)
    Prevents specified subjects from being scheduled at the same time
    Used for combined classes (e.g., Geography SSS3 Iris vs Literature)
11. Combined class teacher consecutive - DATABASE DRIVEN (GenCombinedClassRule)
    Ensures teachers shadowing other subjects don't get 3 consecutive periods

NEW DATABASE TABLES:
====================
- GenSubjectClashRule: Defines which subjects must NOT be scheduled at same time
- GenCombinedClassRule: Defines teacher shadowing for combined classes

WEB INTERFACE:

- /generator/clash-rules/add - Add new subject clash rule
- /generator/combined-rules/add - Add new combined class rule
