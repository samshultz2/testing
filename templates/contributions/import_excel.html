Troubleshooting

Name Matching

The importer matches Excel student names to database students. Names are normalized (uppercase, trimmed whitespace) for matching.

If a student can't be matched, their payments will be skipped and you'll see a warning message.

Common Issues

  • Name mismatch: Ensure student names in Excel exactly match the database (e.g., "JOHN DOE" vs "DOE JOHN")
  • Missing students: Students must be enrolled in SSS3 for the current active term
  • Date format: Dates should be proper Excel dates, not text
