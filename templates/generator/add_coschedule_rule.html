Add Co-Schedule Rule

Group two or more (class, arm, subject) slots so they're always scheduled at the exact same time — e.g. when a combined class splits into 3 or 4 streams for electives, so no stream is idle while the others are in class. Every member needs a specific class and arm; teacher clashes for each subject are already prevented automatically.

If members run a different number of periods per week (e.g. Literature 4×, Accounting 5×, Government 5×), only the smallest count gets grouped up each week — the rest of the larger subjects' periods are scheduled freely.
