Quick Setup: JSS Classes

About JSS Setup

This will create/update JSS1, JSS2, and JSS3 classes with the following settings:

  • No streams - JSS classes don't have Science/Arts/Commercial streams
  • Same arms - All three classes will have the same arms (e.g., Iris, Rose, Lily, Tulip)
  • Same subjects - You'll configure subjects separately after creating the classes
Tip: Use the same arm names as your SSS classes for consistency.
