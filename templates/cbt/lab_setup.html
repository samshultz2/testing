The in-app lockdown (fullscreen, leave-detection, paste/shortcut blocking) is a strong deterrent, but a normal browser can't truly stop a new tab or Alt+Tab. Launching the laptops in kiosk mode removes the address bar, tabs and most escapes — combine it with supervisors for genuinely exam-grade control.

Edit if your lab reaches the server on a different address (e.g. http://192.168.1.10:5000/exam/login). Commands below update automatically.

Windows macOS Linux

Chrome — create a desktop shortcut with this target (or run in Command Prompt):

Edge:

Exit (invigilator only): Alt+F4. For the strongest lockdown, use Windows Assigned Access (Settings → Accounts → Other users → Set up a kiosk) to pin the laptop to a single app with no Windows key.

Chrome — run in Terminal:

Exit (invigilator only): Cmd+Q. Turn on System Settings → Keyboard → disable Mission Control / Spaces shortcuts to reduce escapes.

2 · Before the exam starts

1
Print the passwords. Export each class arm's Student IDs + passwords (CBT → Student Passwords → Excel/Word/PDF) and hand them out.
2
Set a Supervisor PIN (CBT → Supervisor) and share it only with invigilators — for helping students mid-exam without flagging them.
3
Publish the exam and confirm its date, time window and total mark. Students only see it for their class, on its day, within the window.
4
Open the kiosk on each laptop to the address above. Students log in with their Student ID + password, then enter the exam's access password (read it out at the start).

3 · Highest security (optional)

  • Safe Exam Browser (safeexambrowser.org) — free, purpose-built lockdown browser that blocks tab/app switching, screenshots and copy at the OS level. Point it at the portal address above.
  • Use guest / restricted accounts on the laptops, disable USB ports, and disable the on-screen translate / autofill features.
  • Keep the in-app Strict mode on with a low leave-page limit for high-stakes exams.
  • Position invigilators to see screens; the integrity log (per student, in results) records every leave, paste attempt and the time spent away for after-the-fact review.
