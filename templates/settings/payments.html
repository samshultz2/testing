Paystack: create a free account at paystack.com, add your bank account, then Settings → API Keys & Webhooks → copy your Public Key (pk_…) and Secret Key (sk_…). Set the Webhook URL (below) there too.
Flutterwave: from your dashboard Settings → API copy your Public Key (FLWPUBK…) and Secret Key (FLWSECK…). Put your Secret Hash (Settings → Webhooks) in the third box, and set the Webhook URL below.
Monnify: from your dashboard copy your API Key (public box), Secret Key, and Contract Code (third box). Set the Webhook URL below in Monnify → Settings → Webhooks.

How parents pay once this is on:
  • Parents log into the parent portal, open their child’s fee bill, and tap Pay → they’re taken to Paystack to pay by card/transfer.
  • Bursars/finance staff can open a student’s statement and generate a payment link to send a parent (WhatsApp/SMS/email).
  • Every successful payment is recorded against the student automatically and shows up in Finance.
