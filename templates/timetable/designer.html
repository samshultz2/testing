Timetable Designer

Design a timetable (Saturday classes, holiday lessons, exams or a blank grid), print it, save it as PDF — or save it with a name to reload and edit later.

Enter a week number for each session below. Set the first Saturday’s date, then tick any Saturday as lesson-free — that week and every week after it shift to the next available Saturday automatically.

Fastest: paste a whole grid (days × periods)

Paste the whole week as a table. First line = the period times (leave the first cell blank or write “Day”). Each next line = the day, then a subject per period. Separate cells with a comma, a | or a tab (copy straight from Excel/Sheets). Put a teacher in brackets, e.g. Maths (Mr A). Leave a cell blank for a free period or a break.

No spreadsheet? Snap a photo of the timetable, give any chatbot (Claude, Gemini, ChatGPT…) this prompt, then paste its answer above:

Read this class timetable and output it as a comma-separated grid, one row per line:
- First line: the word "Day", then each period's time range — e.g. Day, 8:00-9:00, 9:00-10:00, 10:00-11:00
- Each next line: the day name, then the subject in each period in order. Put the teacher in brackets, e.g. Maths (Mr A). Leave a cell empty for a free period or break.
Output only the rows — no headings, totals or extra text, no code block.
