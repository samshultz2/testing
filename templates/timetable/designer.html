Enter a week number for each session below. Set the first Saturday’s date, then tick any Saturday as lesson-free — that week and every week after it shift to the next available Saturday automatically.

Fastest: paste a whole grid (days × periods)

Paste the whole week as a table. First line = the period times (leave the first cell blank or write “Day”). Each next line = the day, then a subject per period. Separate cells with a comma, a | or a tab (copy straight from Excel/Sheets). Put a teacher in brackets, e.g. Maths (Mr A). Leave a cell blank for a free period or a break. More than one class on the same day? Add the class/stream in brackets after the day, on its own line — e.g. Monday (Science) and Monday (Arts) as two separate lines — and each becomes its own row tagged with that Class/Stream. Leave the brackets off when every class follows the same timetable. A cell with more than one subject for that period (e.g. PHY/GOVT for a split class) is kept exactly as typed — only the brackets are read as a teacher, a bare / never is. Tip: to fill the rest of a day with one activity (e.g. Skill Acquisition), repeat the same text in each remaining period — identical neighbouring cells merge into one block automatically (across periods and, where you use Class/Stream, across streams too).
