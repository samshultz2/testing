How it works

  • With no provider, parents are reached via the one-tap WhatsApp / SMS links on each campaign — nothing else required.
  • Pick Termii or Twilio, paste your key, and a “Send all via gateway” button appears on every campaign — messages go out from the server automatically.
  • Failed numbers are flagged with the provider's error so you can retry.
  • Keys are stored in your own database; switch providers any time.
